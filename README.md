# StockFlow

StockFlow — учебный сайт для небольшого склада. Здесь можно посмотреть, сколько товара осталось, оформить поступление или списание и найти операцию в журнале.

## Как запустить

Установите Node.js версии 22.13 или новее. Откройте терминал в папке проекта и выполните команду.

```sh
npm run dev
```

Затем откройте в браузере [http://127.0.0.1:5173](http://127.0.0.1:5173). В демоверсии уже есть несколько товаров и операций. Ваши изменения сохраняются в базе SQLite в папке `.stockflow/demo/`.

| Роль | Логин | Пароль |
| --- | --- | --- |
| Администратор | `admin` | `stockflow-admin` |
| Сотрудник | `employee` | `stockflow-staff` |

## Что попробовать

Войдите как администратор, добавьте товар и оформите поступление. Затем войдите как сотрудник, спишите часть товара и проверьте новый остаток. При списании укажите основание, например «повреждена упаковка». Оно появится в журнале операций.

## Как разместить на Railway

1. Создайте сервис из репозитория GitHub и подключите к нему том (Volume) с путём `/data`. В этой папке будет храниться база.
2. В настройках сервиса задайте `STOCKFLOW_ADMIN_PASSWORD` и `STOCKFLOW_EMPLOYEE_PASSWORD`. Придумайте для каждой роли свой пароль длиной от 12 символов. Эти пароли используются при создании базы.
3. Разверните сервис и нажмите **Generate Domain** в настройках сети. На сайте войдите как `admin` или `employee` со своим паролем.
